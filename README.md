# Nula SDDM Theme

Nula is a sleek, minimalist login theme for Linux. Built for the **Nula Linux** ecosystem, it features a fluid user avatar carousel with smooth transitions and optimized session controls.

## 📸 Screenshots
![Nula SDDM Preview](https://raw.githubusercontent.com/l7p3x/Nula-SDDM/main/preview.png)

## 🚀 Features
* **Fluid Carousel:** Continuous position and opacity animations for seamless user switching.
* **Modern UI:** Clean layout focused on high contrast, custom borders, and typography.
* **Smart Controls:** Native SDDM session fetching and auto-focus password field.
